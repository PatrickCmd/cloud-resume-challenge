# Changelog

All notable changes to the portfolio frontend. The redesign below was delivered as one
commit per numbered item on branch `claude/funny-clarke-kranjz`; the audit that preceded it
is in `docs/PORTFOLIO_AUDIT.md`.

## Unreleased — fixes from the first live audit

Found by testing https://patrickcmd.dev after the redesign shipped (responsiveness,
UI/UX, accessibility, data flow). One commit per item.

1. **Blog deep links.** `/blog` is a read-only list in the site's style; posts link to
   `/blog/<slug>`, so they can be shared and Back returns to the list. The old editor
   tab now lives only under `/admin`. The static fallback post uses the real slug.
2. **Content-free post lists.** Backend `GET /blogs?include_content=false` returns posts
   without bodies (the single published post is 370 kB because of an embedded image);
   the Writing section and the blog list use it, so the home page downloads 828 B
   instead of 370 kB. The post page fetches the body by id. **Needs a backend deploy.**
3. **`/projects` redesigned.** Curated projects from `content/projects.ts` first, then
   API-published projects that are not already covered, with the same cards as the
   home grid. `/projects/p/:id` shows an API project's long description.
4. **Certifications.** `content/certifications.ts` mirrors the API: 14 credentials with
   Credly / ExamPro / DataTalks.Club / Coursera links, official Credly badge artwork
   (`public/badges/*.png`), and the AI courses (RAG, LLM Zoomcamp, GenAI Bootcamp,
   MLOps Zoomcamp) listed. Resume PDF regenerated.
5. **Shorter home page on phones.** Three projects and three roles by default with
   "Show more", 2:1 covers, skills as chips, a three-column badge grid and a collapsed
   courses list. iPhone 13 page height: ~11,900 → ~8,700 CSS px.
6. **Sweep.** Per-route `document.title`, accessible names on the blog admin icon
   buttons, `noindex` on the 404 shell, valid `ol > li` timeline markup, API read time
   shown as "n min read", one `h1` per blog post (markdown `#` renders as `h2`).

Not changed: inline text links under 24 px tall are flagged by target-size heuristics
but are exempt as in-sentence links; the blog post's embedded base64 image should move
to S3 in the admin editor to shrink the post itself (content change, not code).

## Previous release — professional redesign

### Prerequisite (chore)
- Lint and typecheck are green (0 errors; 123 warnings remain, mostly `no-explicit-any` in
  tests and shadcn `only-export-components`). `npm run typecheck` added.
- Removed the unused Vite starter `App.css`; Google Fonts moved from a CSS `@import` to
  `index.html`.

### 0. Content model
- `src/content/` holds every piece of profile copy as typed TypeScript: `profile.ts`,
  `skills.ts`, `experience.ts`, `projects.ts`, `certifications.ts`, `writing.ts`, plus
  `case-studies/*.md`. Components no longer contain copy.

### 1. Metadata and sharing
- Title "Patrick Walukagga — Software & AI Engineer", single-sentence description, canonical
  URL, theme-color, OpenGraph and Twitter cards with a committed `public/og.png`
  (1200×630, generated by `scripts/generate-og.cjs`), Person JSON-LD.
- `sitemap.xml` is written at build time by a Vite plugin from the project list;
  `robots.txt` references it and disallows `/admin`.
- All Lovable references removed, including the `lovable-tagger` dependency.

### 2. Hero
- Positioning line, availability pill, "View projects", "Ask my AI twin" (new tab) and
  "Resume" (static PDF) CTAs, GitHub and LinkedIn icons only.
- `public/Patrick-Walukagga-Resume.pdf` is generated from the content files by
  `scripts/generate-resume.cjs`; the client-side jsPDF generator and its 420 kB of
  dependencies are gone.

### 3. About + Skills
- One paragraph and a four-item fact list; four grouped skill lists, no progress bars.

### 4. Experience
- Timeline from `experience.ts` with outcome bullets and tech tags; roles that ended more
  than five years ago collapse behind "Show earlier roles".

### 5. Projects
- Six featured cards (Digital Twin and the MLOps pipeline first) with vector covers.
- `/projects/:slug` case studies rendered from markdown (Context, Architecture, Decisions,
  Results) for Digital Twin, the MLOps pipeline and this site.
- `/projects` keeps the full API-driven list.

### 6. Certifications + Writing
- Compact AWS badge row plus a one-line list of other credentials.
- Writing section shows the latest three published posts from the portfolio API with a
  static fallback (`content/writing.ts`). `/blog` and `/blog/:slug` serve the full list and
  individual posts.

### 7. Contact + Footer
- Email, LinkedIn, GitHub buttons and a repeated AI-twin CTA. X appears only when a handle
  is set in `profile.ts`.
- Footer with location, copyright, "Built with" links, source link and the visitor counter.

### 8. Global UI
- Shared layout with skip link and landmarks; sticky anchor nav with active-section
  highlighting and a mobile sheet menu; theme follows the system by default with a
  pre-paint script.
- Owner login moved off the public page to `/admin` (dashboard and editors live there).
- Every route except the home page is lazy-loaded. Home chunk: 144 kB gzip (was 642 kB).
- Primary green darkened for AA contrast on white; `prefers-reduced-motion` respected.
- Lighthouse on the production build, served locally: desktop 100 / 100 / 96 / 100,
  mobile 97 / 100 / 96 / 100 (performance, accessibility, best practices, SEO).

### 9. CI and docs
- `.github/workflows/frontend-ci.yml` runs lint, typecheck, tests and build on pull
  requests and pushes to `main`.
- README documents `src/content/`, the routes and the asset scripts.
